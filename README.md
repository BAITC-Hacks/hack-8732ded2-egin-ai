# hack-8732ded2-egin-ai

Hackathon team repository for egin.ai.

Проект разделён на два приложения:

 - `frontend` — React, Vite, TypeScript, Axios, Tailwind CSS и shadcn/ui.
 - `backend` — Express.js и TypeScript.

## Запуск

В отдельных терминалах:

```bash
cd frontend
npm install
npm run dev
```

```bash
cd backend
npm install
copy .env.example .env
npm run dev
```

Frontend: `http://localhost:5173`, API: `http://localhost:3000/api/health`.
