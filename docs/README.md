# WindCast Agent — кратко о проекте

## Что мы сделали

WindCast Agent превращает прогноз ветра в готовое бизнес-решение для ветропарка: сколько энергии будет произведено, сколько можно заработать, где появится риск отклонения и какие действия стоит принять.

## Какую проблему решаем

Обычный прогноз погоды сам по себе не отвечает на главный вопрос бизнеса: сколько энергии реально получится отдать в сеть и во что обойдётся ошибка прогноза.

Мы связываем погоду, исторические данные турбин и коммерческие параметры в одном расчёте.

## Как работает система

1. Загружаем исторические CSV-данные по турбинам и проверяем их качество.
2. Калибруем power curve каждой турбины и считаем MAE/RMSE.
3. Получаем почасовой прогноз ветра Open-Meteo по координатам и высоте турбин.
4. Рассчитываем прогноз мощности и уверенность по каждому часу.
5. Agent объясняет результат, отмечает резкие изменения ветра и проблемные часы.
6. Система объединяет турбины и переводит прогноз в деньги, риск и операционную рекомендацию.

## Что показывает продукт

- прогноз генерации по каждой турбине и по ветропарку;
- ожидаемую выручку;
- отклонение от заявленной мощности;
- потенциальный штраф за дисбаланс;
- уровень риска: low, medium или high;
- часы низкой уверенности и резкие ramp-события;
- рекомендацию: нужен резерв и корректировка плана или можно продолжать штатную работу.

В интерфейсе есть три основных экрана: прогноз ветропарка (`/forecast`), качество данных (`/data-quality`) и калибровка модели (`/calibration`). Интерфейс поддерживает русский, английский и казахский языки.

## Какие API работают

Backend работает на `http://localhost:3000`, все маршруты используют префикс `/api`.

| Метод | API | Что делает |
| --- | --- | --- |
| GET | `/api/health` | Проверяет доступность сервиса |
| GET | `/api/dataset` | Возвращает данные и качество обеих турбин |
| GET | `/api/dataset/:turbineId` | Возвращает данные одной турбины |
| POST | `/api/dataset/upload` | Загружает CSV и сохраняет его в SQLite |
| GET/POST | `/api/calibrate` | Калибрует модель; POST также пишет лог |
| POST | `/api/agent/run` | Строит прогноз и объяснение для одной турбины |
| POST | `/api/wind-farm/business-impact` | Возвращает прогноз и бизнес-эффект ветропарка |
| POST | `/api/walk-forward-simulate` | Проверяет модель на историческом периоде |

## Какой результат приходит

Главный endpoint `/api/wind-farm/business-impact` возвращает:

- `expectedGenerationMWh` — ожидаемую выработку;
- `expectedRevenue` — ожидаемую выручку;
- `imbalanceRiskMWh` — объём отклонения от обязательства;
- `potentialPenalty` — возможный штраф;
- `riskLevel` — общий уровень риска;
- `recommendation` — конкретное действие для оператора;
- `hourly` — почасовую мощность, обязательство, отклонение и уверенность;
- показатели по каждой турбине и объяснение работы agent.

## Ценность для бизнеса

WindCast Agent помогает заранее скорректировать план поставки, подготовить резерв и снизить риск штрафов. Оператор видит не просто цифры прогноза, а понятный ответ: сколько произведём, сколько заработаем, где отклонимся и что делать дальше.

## Технологии

Frontend: React, TypeScript, Vite, React Router, Axios, Tailwind CSS, i18next и Lucide React.

Backend: Node.js, TypeScript, Express, Multer, SQLite, Open-Meteo Single Runs API и OpenAI Responses API. Если AI-анализ недоступен, система использует детерминированное объяснение и не останавливает расчёт.
